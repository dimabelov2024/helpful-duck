Helpful Duck 🦆🤖

Helpful Duck is an open experimental biped robot platform focused on modular hardware, AI integration and autonomous operation.

Current version: v3.6.1

Core features

* Modular biped robot architecture
* AI integration
* Removable iPhone module
* Independent onboard computer
* Robotic manipulator
* Replaceable battery cartridge
* Autonomous PitStop battery swapping concept
* Modular sensors, displays and communication systems
* Designed for rapid prototyping and 3D printing

Project Documentation

Full project documentation, engineering concepts and technical drawings are available in the /docs directory.

Current status

🚧 Active prototype development

The project is currently moving from digital design and engineering documentation toward physical prototyping.
